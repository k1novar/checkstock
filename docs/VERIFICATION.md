# Отчёт о проверке

Дата: 13.11.2026. Статус отражает фактически выполненные проверки.

## Выполнено локально (SQLite)

Команда из корня проекта: `python -m pytest -q` с установленными зависимостями и SQLite во временном каталоге.

**Результат: 26 passed, 4 skipped.** (4 конкурентных теста пропущены, так как SQLite не поддерживает блокировки `FOR UPDATE`).

Проверено через FastAPI TestClient с реальным SQLAlchemy и отдельной БД для каждого теста:
- начальные количества и повторная инициализация без повторного прихода;
- раздача главной страницы, JavaScript и health endpoint;
- приход, повтор того же UUID и конфликт UUID с изменёнными данными;
- резерв, отправка, доставка, отмена и повторные подтверждения FBS;
- отправка и приёмка ФФ/FBO, отсутствие повторного зачисления;
- нехватка на выбранном ФФ при достаточном общем количестве;
- невозможность отгрузить зарезервированные единицы через FBO/перемещение;
- архивирование с остатками, резервами и входящей поставкой, вывоз остатка;
- добавление склада, переименование, нулевые остатки, сохранение исторических названий;
- неправильные количества, неизвестные объекты, недопустимые переходы;
- полный демонстрационный сценарий;
- баланс после каждого шага и реконструкция остатков/резервов из журнала.

## Выполнено через Docker (PostgreSQL 17)

Команда `docker compose --profile test run --build --rm tests` выполнена успешно.
**Результат: 30 passed.** Все тесты, включая 4 конкурентных теста на блокировки `FOR UPDATE`, прошли без пропусков.

## Выполнено в браузере (визуальная проверка)

Сквозной сценарий из README пройден вручную в браузере по адресу `http://localhost:8000`. Проверены: создание прихода, резерв FBS, перемещение между ФФ, отправка FBO, приёмка, архивация склада, поиск, фильтрация операций и отображение истории. Результат зафиксирован на видео.

## Не удалось проверить здесь

- Нагрузочные испытания и одновременную работу нескольких пользователей в разных вкладках.
- Совместимость с реальными кабинетами Wildberries (не входит в объём тестового задания).
- Аудит безопасности и готовность к публичной эксплуатации (прототип не заявляет об этом).
